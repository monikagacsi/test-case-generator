**User Story:**
As a **budget-conscious saver**, I want to **automatically round up every card transaction to the nearest dollar and transfer the difference into my savings vault**, so that **I can build savings passively over time**.

 **Acceptance Criteria:**
  * Users can enable or disable the "Round-Up" feature with a single toggle in settings.
  * A settings menu allows users to choose a multiplier (e.g., exact difference, 2x, or 3x).
  * Transactions display both the base purchase amount and the rounded-up contribution in the history log.
