**User Story:**
As a **collaborating team member**, I want to **be alerted when another user is editing the same paragraph and see inline change suggestions**, so that **we don't accidentally overwrite each other's work**.

 **Acceptance Criteria:**
  * Active collaborators are displayed as profile avatars at the top of the document.
  * When two users edit the same block simultaneously, a non-intrusive banner appears offering options to "Accept Incoming," "Keep Mine," or "Merge."
  * Changes made by other users update in real-time with a color-coded cursor indicator and the editor's initials.
