**User Story:**
As a **system administrator**, I want to **select and update multiple user roles simultaneously via a CSV upload**, so that **I can onboard department cohorts efficiently without manual entry**.

 **Acceptance Criteria:**
  * The admin panel accepts standard `.csv` files containing user emails and target roles.
  * A validation preview screen displays successfully matched accounts and highlights any formatting errors or unknown emails prior to confirmation.
  * An automated audit log records the admin's ID, timestamp, and the count of modified accounts upon completion.
