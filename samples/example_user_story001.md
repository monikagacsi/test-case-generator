**User Story:**
As a **first-time visitor**, I want to **complete a purchase as a guest without creating an account**, so that **I can buy an item quickly without friction**.

**Acceptance Criteria:**
  * The checkout page includes a prominent "Continue as Guest" option.
  * Only essential details (shipping address, payment info, email for receipt) are required.
  * After purchase, users are presented with a one-click option to save their password and create an account using their entered details.
