**User Story:**
As a **visually impaired user relying on a screen reader**, I want to **navigate the financial analytics dashboard using standard ARIA landmarks and keyboard shortcuts**, so that **I can review my monthly spending independently**.

 **Acceptance Criteria:**
  * All interactive charts have descriptive text alternatives (`aria-label`) summarizing the data trends.
  * Focus states are clearly visible when navigating via the `Tab` key.
  * Heading hierarchies (`H1` to `H3`) are structured sequentially without skipping levels.
